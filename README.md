# 新闻图表设计素材库

本仓库保存素材、数据库和说明。素材处理和检索程序保存在仓库外的本地工具目录。正式数据库目前尚无素材；`samples/` 另有三张报纸裁切图和示例记录，供对接试读，不计入正式合格素材。

`assets.sqlite3` 是独立 SQLite 数据库，表 `metadata` 的 `schema_version` 为 1；表 `assets` 的 `relative_path` 相对于本仓库根目录，`tags_json` 是 JSON 标签数组。前端应以 SQLite 只读方式打开，不得修改或合并本库。数据库由素材维护者单独更新。当前接口仅是待双方确认的提案，尚未验证前端集成。

用户表示本次版面和裁切元素可以公开；具体授权文件尚未提供。素材的正式审核与许可记录仍待补充。通过审核的正式素材计划放在本仓库的 `assets/`，不含处理代码。试读方法与问题见 [samples/README.md](samples/README.md)。
